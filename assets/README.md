# Logo assets

| File | Purpose |
| --- | --- |
| `logo.svg` | static logo, dark background |
| `logo-transparent.svg` | static logo, transparent background |
| `logo-animated.svg` | animated logo (unlock, lock, glow, sheen; respects `prefers-reduced-motion`) |
| `icon.svg` | rounded-square variant used to render `icons/icon{16,32,48,128}.png` |
| `icon-animated.svg` | rounded variant used to render `icons/anim/*.png` (toolbar animation frames) |
| `icon-inline.svg` | markup inlined in `popup/popup.html` (header logo, animates on hover) |

PNG icons and animation frames are screenshots of the SVGs (headless Chrome, transparent background) at 16/32/48/128 px.
